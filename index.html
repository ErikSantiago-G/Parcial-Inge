Flujo Integral de los Datos

1. Ingesta desde SQLite

Nuestra infraestructura central está fundamentada en una base de datos relacional local exportada como CSV.

  • Conexión mediante librería Python sqlite3
  • Creación programática de la BDD a través de scripts SQL (`.sql`)
  • Importación de tablas críticas: Inversiones, Proyectos y Empresas.

2. Exploración (EDA)

Análisis enfocado en entender la integridad atómica y el esquema macro de las fuentes.

  • Detección de tipologías (Int, Float, Object) y revisión nula.
  • Comportamiento de la dispersión de datos.
  • Confirmación de integridad relacional (Claves foráneas y primarias).

3. Conformación del Data Warehouse

Normalización en formato de consultas Dataframe empleando el ORM visual de pandas.

  • Intersecciones multivariables mediante joins exhaustivos (merge()).
  • Saneamiento de redundancias (limpieza exhaustiva de claves superpuestas).
  • Desnormailización final: Un consolidado central analítico robusto.

4. Insights y Consultas SQL

Se resolvió la algoritmia y peticiones de la fase inicial mapeando métricas claves del negocio.

  • Sumatorias de inversión por categorización tecnológica en USD.
  • Patrones sociodemográficos de ubicación de refinerías o plantas (Eólica, Fotovoltaica).
  • Predicción basada en cruces algorítmicos.

Orquestación de Datos: Airflow & Docker

Sinergia entre Apache Airflow y Docker para flujos ETL

La integración de Apache Airflow y Docker es el estándar de la industria para garantizar pipelines de datos robustos, escalables y reproducibles. Mientras que Docker aísla las dependencias del ecosistema analítico en contenedores ligeros (como la BD o el Dashboard), Airflow orquesta, monitoriza e inicializa estos procesos secuencialmente de forma automatizada para todo el flujo Extract-Transform-Load.
